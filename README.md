# Darshan  - Portfolio

## 🌐 Live Demo

👉   https://darshanr.vercel.app

## 🛠️ Installation

```bash
git clone https://github.com/darshan2006-coder/darshan-portfolio
cd darshan-portfolio
npm install
npm run dev
```
